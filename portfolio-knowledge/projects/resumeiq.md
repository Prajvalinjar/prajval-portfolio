## Short Summary
ResumeIQ AI is an intelligent platform that parses and evaluates engineering resumes, providing actionable feedback to help candidates pass ATS filters.

## Architecture
The system uses Next.js for a blazing fast frontend and serverless API routes that stream responses directly from OpenAI's advanced models.

## Engineering Challenges
Handling non-standard PDF formats and ensuring prompt injection safety were key challenges.

## Key Features
- Instant ATS Scoring
- Bullet Point Recommendations
- Missing Keywords Detection
