## Short Summary
Customer Sales Analytics is an end-to-end business intelligence pipeline that extracts transactional data, standardizes schemas, and visualizes retail forecasting metrics.

## Architecture
Built using Python cron jobs for data cleaning (ETL) and PostgreSQL as a central data warehouse supporting Power BI dashboard views.

## Engineering Challenges
Standardizing legacy databases containing inconsistent formats, and processing 2M+ rows of transactional logs efficiently.

## Key Features
- Automated Reporting Pipeline
- Revenue Trend Forecaster
- Dynamic Customer Segmentation
